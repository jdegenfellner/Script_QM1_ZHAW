The prior is Beta(α, β) with α = 1 + 20 · mode and β = 1 + 20 · (1 − mode). For mode 0.2 this gives α = 5 and β = 17, as in the script.

Bayes' theorem: posterior ∝ likelihood × prior. With a Beta prior and binomial data the posterior is again a Beta distribution, Beta(α + X, β + n − X). The script computes the same curve by numerical integration.

Watch the posterior move from the prior mode towards X / n. It always lies between the two.
