For a Beta(α, β) prior and h heads and t tails the posterior is Beta(α + h, β + t). Each toss just adds 1 to α (heads) or β (tails).

Only the number of heads and tails matters, not their order (data-order invariance). Switch the prior while the data stay: the posteriors of all priors move towards the same region as the number of tosses grows.
