H₀ and the truth: a tree of the four possible outcomes

A hypothesis test is carried out. Either the null hypothesis H₀ is true or it is false, and the test either rejects H₀ or does not. Set how often H₀ is true, the significance level α and the type 2 error probability β. The tree, the branch thickness and the result follow immediately.

Reading the tree: the first split is the prior, how often H₀ is true. The second split holds the error probabilities: α if H₀ is true, β if H₀ is false. Green leaves are correct decisions, red leaves are wrong decisions. The two dashed arrows collect the rejections of H₀. The true rejections are the share 1 − β (the power) of all false nulls, the false rejections are the share α of all true nulls. How many of the rejections are false depends on all three numbers, not on α alone. This is the same tree as in Bayes' theorem.
