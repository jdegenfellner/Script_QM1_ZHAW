Publication bias: what the literature shows when mostly “significant” results appear

Many studies of the same question are run. Each one estimates the effect with some noise. Set the true effect (0 means that H₀ is true), the sample size and how many of the unwanted results, those that are not “significant” in the hoped-for direction, are published anyway. The forest plot shows all studies. Filled dots were published, hollow dots stay in the drawer.

0: no effect, H₀ is true
0 %: only wanted results appear. 100 %: everything appears

Each study compares two groups of size n with standard deviation 1 (effects in SD units). The estimate is the true effect plus random noise with standard error √(2/n); the sample size varies between studies. The meta-analysis pools the studies with inverse-variance weights (fixed effect, since all studies share one true effect). A result is “wanted” if its p-value is below α and the estimate is positive. Only wanted results are always published, all other results are published with the share set above. The noise is fixed for a given set of studies, so moving a slider changes only the setting, not the random draw. The pooled estimate of the published studies is too large because selection by p-value keeps the studies that happened to overshoot (Gelman and Carlin 2014, “type M error”).
