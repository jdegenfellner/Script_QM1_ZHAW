How many rollators does the hospital have?

The hospital numbers its rollators 1, 2, 3, … N. The app has secretly chosen N. Every click finds one more rollator at random. Watch how each number changes the posterior of N.

Every N below the highest number found is impossible. Among the remaining values, a small hospital is more plausible: the more rollators there are, the less likely it is to find exactly these ones.

Each new rollator updates the posterior. Today's posterior is tomorrow's prior.
