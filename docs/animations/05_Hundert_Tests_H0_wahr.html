Every single test has only an α chance of a false alarm. But with 100 tests, at least one false alarm is almost certain, and the average run produces about 100 × α of them. If only those tiles were reported, they would look like discoveries. This is the multiple-testing problem behind p-hacking. (Under H0 a p-value is uniformly distributed between 0 and 1, which is exactly what is simulated here.)
