The p-value answers how surprising the estimate would be if the true difference were zero. It says nothing about the size of the difference. With a large enough sample, a difference far too small to matter has a tiny p-value. What changes with n is the precision: the interval for the difference shrinks around the same estimate. Calculation: standard error = SD · √(2/n), z = difference / standard error, p = 2 · (1 − Φ(|z|)), normal approximation, equal group sizes, the observed difference set equal to the true one. See also Wasserstein and Lazar (2016), principle 5: a p-value does not measure the size of an effect or the importance of a result.
